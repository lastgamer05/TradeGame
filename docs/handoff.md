# 인수인계 (2026-10-06 기준, 도시 거리 작업 반영)

다른 계정·다른 세션에서 이어서 작업할 때 이 문서부터 읽는다. 규칙은 `CLAUDE.md`, 기획은 `docs/design.md`, 도시 탐방 규격은 `docs/city_spec.md`, 1막 이야기는 `docs/story.md`.

## 시작하기

1. 저장소: https://github.com/lastgamer05/TradeGame (공개). 작업한 PC에서는 `D:\github_repo\TradeGame`.
2. Godot 4.7.2 콘솔판으로 테스트를 돌린다 (명령은 `CLAUDE.md`). 새로 받은 저장소는 `--import`를 한 번 붙여 돌려야 한다.
3. 그림 작업: Python 3 + Pillow (`art_src/*.py`), 이미지 생성은 바르코(VARCO) MCP 연결과 브라우저에 열린 바르코 커스텀 워크플로가 필요하다.
4. `main`에 push하면 웹 빌드가 GitHub Pages(https://lastgamer05.github.io/TradeGame/)에 자동 배포된다. push하려면 그 PC의 git에 저장소 쓰기 권한이 있어야 한다.

## 지금까지 만든 것

- **교역**: 도시 8곳, 교역품 22종, 특산·수요 시세, 판매 압력, 시세 %, 평균 구입가와 이익, 거래 평판.
- **진영 정세**: 거래가 진영 세력을 키우고, 점유율이 문턱을 넘으면 정세 사건(반란 격화, 그린하우스 봉쇄, 단속 강화, 약탈 증가)이 시세를 바꾼다.
- **이벤트**: 이동·도착·구역 이벤트 53개, d20 판정. 정세 사건과 점유율에 따라 뜨는 이벤트가 달라진다.
- **전투**: 정육각형 타일(24x13), 30도 대각선으로 비스듬히 본 화면, 엄폐·시야·경계·수류탄·탑승 도주·항복 요구, 차량 부위 파손과 정비소 수리, 애니메이션.
- **도시 탐방**: 큰 지도(도시 입구) → 도착 장면(첫 방문 소개 대화) → 도시 거리 → 구역(배경, NPC 대화, 거래·정비·소문, 구역 이벤트).
- **도시 거리**: 옆에서 본 거리를 주인공이 걸어 다닌다(←→ 또는 클릭). 왼쪽 끝이 도시 입구, 구역 입구 4곳 앞에 그 구역 NPC가 서 있어 다가가면 이름표가 뜨고 E로 들어가거나 말을 건다. 행인이 오간다. Tab은 도시 정보(진영, 평판, 특산·수요, 의뢰, 정세). 배치는 `data/towns.json`.
- **이벤트 반복 줄이기**: 도착 30%, 구역 30%(머무는 동안 1번, 같은 구역 재입장엔 없음), 이동 65%. 한 번 뜬 이벤트는 10일 동안 다시 안 뜬다 (`economy.json`의 `events`, 이벤트별로 `trigger.cooldown_days`로 바꿀 수 있다).
- **전투 늘리기**: 이동 이벤트 `raider_ambush`(매복, 대기 3일), `gas_station_raid`(폐주유소, 대기 4일)와 가벼운 조우 `raider_scouts`(약탈자 3명, 승률 약 95%)를 더했다. 약탈자 바리케이드에 "싸운다" 선택지, 바리케이드·전쟁 기계 가중치 상향.
- **판정 주사위 연출**: 판정이 있는 선택지를 고르면 발더스 게이트처럼 화면 가운데 난이도·보정치·성공 확률을 띄우고, 굴리면 d20이 굴러가다 멈춘 뒤 합계와 성공·실패(자연 20은 대성공, 1은 대실패 표시만)를 보여 준다 (`dice_roll_view.gd`). 규칙은 그대로 d20 + 능력치 ≥ DC.
- **연출**: 프롤로그가 그림 6장짜리 컷신이 됐다 (전쟁의 끝 → 하나 남은 불빛 → 운반꾼 → 플래시백과 선택 → 그린하우스 → "잔류전력" 제목). 화면이 천천히 흐르고 자막이 타자기처럼 찍힌다. 대화창 대사도 타자기처럼 찍히고, 도착 장면의 도시 이름은 내려오며 나타난다. 새 컷신은 `data/cutscenes/`에 그림과 줄만 적으면 된다.
- **프롤로그와 초반 안내**: 새 게임이 세계·주인공 소개 프롤로그로 시작하고, 1막 줄기를 8단계 목표로 안내한다 (`guide.json`, 윗줄 아래 목표 표시, 거리의 ▼ 표시). 자세한 건 `docs/story.md` 1절.
- **글 줄이기**: 대사·이벤트·도착 대화를 짧고 입말에 가깝게 다듬었다. 구역 화면의 설명·역할·진영 글을 뺐고, NPC 역할은 짧은 직함만 남겼다. 대화 끝 선택지는 "그만 간다".
- **이야기(1막)**: NPC 32명 대화와 도시 소개 대화 8개, 세력 대표 의뢰 8개, 동료 4명(이안, 피스, 모래, 한) 영입과 이탈, 발전소 노후화 숨은 줄기와 주인공의 과거 떡밥.
- **그림**: 요즘 픽셀 게임 스타일(이스트워드, 씨 오브 스타즈). 도시 8, 도시 거리 8, 구역 32, 초상화 32(플레이어와 눈 맞춤), 거리 NPC 전신 32, 주인공 걷기 4장, 행인 4, 전투 유닛 8, 소품 16, 전투 바닥 5, 아이콘 25. 원본은 `art_src/`.

## 알려진 빈틈

- 여관·모닥불의 "용병 고용"(`recruit` 서비스)은 자리만 있다.
- 거리 행인 4명은 모든 도시가 같이 쓴다. 도시마다 다른 행인, NPC 걷기·몸짓 동작은 아직 없다.
- 거리 NPC 시트 2~4(언더그리드부터)는 헬리오스 시트를 스타일 참고로 다시 뽑아 비율을 맞췄다. 얼굴이 초상화와 조금 다른 인물이 있을 수 있다.
- `locations.json`의 구역 `description`은 이제 화면에 안 나온다 (데이터만 남아 있다).
- 대화에서 생긴 결과(전력, 화물 변화)가 아래 로그에 남지 않는다 (대화창 안에서는 보인다).
- 진영 점유율이 엔딩으로 이어지지 않는다. 엔딩 자체가 아직 없다 (2·3막 미작성).
- 오토바이, 차량 모듈 장착, 동물 동료, 폐허 탐험은 기획만 있고 구현 안 됨.
- 전투 스프라이트는 한 방향 그림을 뒤집어 쓰고, 걷기·사격 동작 프레임이 없다.
- 시세, 전력, DC, 전투 수치는 모두 임시 밸런스 값이다 (`tests/balance_sim.gd`로 전투 승률 확인).

## 작업 방식 메모

- 사용자는 한국어로 짧게 지시하고, 그림·화면은 비교 이미지를 보고 고르는 걸 좋아한다. 큰 방향을 바꾸기 전에는 한 장면으로 먼저 시험해 보여 주고 확인받았다.
- 큰 작업은 `docs/city_spec.md`처럼 규격(데이터 형식, 함수 이름, 담당 파일)을 먼저 정하고, 담당 파일이 겹치지 않게 나눠 여러 에이전트에 병렬로 맡긴 뒤 합쳤다.
- 바르코: 새 계정에서는 VARCO 3D MCP를 연결하고 브라우저에 커스텀 워크플로 편집기를 열어 둬야 한다. 기존 워크플로에 예전 결과물(초상화 시트 등)의 `/api/objects/...` 주소가 남아 있어 참고 그림으로 재사용할 수 있다. 도시 거리 작업 노드는 캔버스 x 12000 이후.
- 화면을 바꾸면 `tests/screenshot.gd`의 모드(`demo`, `battle:<조우>`, `map`, `hub:<도시>[:x]`, `location:<구역>`, `dialogue:<npc>`, `arrival:<도시>`)로 찍어서 직접 확인한다.
